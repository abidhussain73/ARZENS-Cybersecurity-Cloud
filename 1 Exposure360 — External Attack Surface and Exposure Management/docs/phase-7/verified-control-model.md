# Verified Control Model

Verified control evidence is an evidence-backed record, not a permanent Boolean. It includes tenant scope, optional finding/asset/relationship linkage, control type/key, verification state, effectiveness, confidence, verification time, expiry/freshness policy, source references, and metadata.

Applicable verified controls reduce only mapped factor categories. Per-factor and global caps prevent controls from reducing contextual risk to zero automatically. The current global cap is `0.50`, recorded under `verified-control-registry-v1`.
